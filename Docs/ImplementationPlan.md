# Implementation Plan (Build It Step-by-Step)

## Phase 1 (Foundation Only)
1. Player movement
2. Third-person camera
3. Inventory
4. 60-second countdown
5. Resource collection

> Do not build all systems at once. Finish and test this phase first.

## Phase 2 (Core Survival Systems)
- Fungus System
- Rebellion System
- Expedition System
- Dialogue System

## Phase 3 (Optimization & Feel)
- Performance optimization (CPU/GPU/RAM)
- Smoother animation blending
- VFX polish (dust, camera shake timing, post FX)

## Phase 4 (Content & Presentation)
- Main menu
- Sound effects
- Dynamic music passes
- Cinematic scenes

## Testing Guidance
- Test each system directly in Unity Play Mode (or Unreal PIE for UE pipeline).
- Validate:
  - No console errors
  - Stable FPS
  - Animations play correctly
- Start with ready assets from Unity Asset Store / FAB to accelerate prototyping.
- Always review and refine generated code manually.
